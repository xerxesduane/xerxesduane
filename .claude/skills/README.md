# Project skills

UI/UX design skills for this site, committed to the repo so they persist
across machines, accounts, and Claude Code sessions.

| Skill | Status | Notes |
|---|---|---|
| `design-taste-frontend` | Complete | Self-contained. No external files. |
| `ui-ux-pro-max` | SKILL.md only | Needs `scripts/search.py` + data CSVs + `references/`. |
| `impeccable` | SKILL.md only | Needs `reference/*.md` (~30) + `scripts/context.mjs`, `pin.mjs`. Also installable via `npx impeccable`. |
| `ui-styling` | SKILL.md only | Needs `references/*.md` + `scripts/*.py`. |

To complete a partial skill, copy its full folder from the source machine:

    xcopy /E /I "C:\Users\<user>\.claude\skills\<name>" ".claude\skills\<name>"

Design direction of record: Modern Dark Cinema (via ui-ux-pro-max),
warmed to a Dubai gold + olive palette. See README.md.
